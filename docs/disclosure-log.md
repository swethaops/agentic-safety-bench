# Responsible Disclosure Log

When a scanner is found to pass a vulnerable agent as safe, or to report
misleading verdicts, the maintainer is notified before results are published.

This log records every disclosure, its status, and the outcome.

---

| date | tool | version | finding | notified | response | published |
|---|---|---|---|---|---|---|

---

## Process

1. Identify the finding with a reproducible configuration (scanner version, agent config, run ID).
2. Contact the tool maintainer via their security disclosure channel or GitHub issue.
3. Provide: the reproduction steps, the action log showing the ground-truth outcome, and the scanner's verdict.
4. Allow a reasonable response window (suggested: 30 days for a fix, 14 days for acknowledgement).
5. Update this log with the response and the date results were published.

The goal is to help tools improve, not to rank or embarrass them.
